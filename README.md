# Shoppy-globe Backend API

    shoppy globe is an e-commerce backend API built using Node.js,Express.js & MongoDB

# The API Provide Functionality for :

    - User Registration
    - User Login
    - JWT Authorization
    - Product Management
    - Shopping Cart Management
    - CRUD operations for cart items
    - MongoDB database integration
    - API Validation and error handling

# Technologies Used

    - Node.js
    - Express.js
    - MongoDB
    - Moongoose
    - JWT (JSON Web Token)
    - Nodemon
    - Thnuder Client
